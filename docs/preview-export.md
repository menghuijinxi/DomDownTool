# 预览器导出与导出任务

`DomDownToolPreview.exe` 的预览页只负责查看地图和调整范围。点击工具栏的“导出”后，会
进入独立的导出配置页；点击“任务”可以随时查看全部导出记录。旧 WebView2 预览 UI 不再
参与此流程。

## 预览页设置范围

1. 在预览页选择地图来源、GIS 分类和颜色。
2. 使用“中心点 + 半径”时，在“半径”输入导出半径（米）。默认值为 `0`，此时不显示
   范围框。
3. 半径大于 `0` 时，地图中心上方会绘制黄色方框。地图拖动或缩放后，方框会跟随新的
   中心点；实际导出范围是与该范围相交的完整瓦片方形。
4. 也可以点击半径旁的 KML 文件按钮，或把 `.kml` 文件直接拖入预览窗口。导入成功后地图
   会缩放到 KML 范围，并用黄色描边和半透明填充显示多边形。
5. 点击“导出”打开配置页。范围模式、层级、地图源、GIS 分类和颜色会从预览页初始化，
   但配置页中的值可以继续修改。

### KML 范围

导出页的“下载范围”可以在“中心 + 半径”和“KML 范围”之间切换。KML 模式支持 KML 2.2
中的 `Polygon`，也支持 `MultiGeometry` 中包含的多个 `Polygon`。坐标按 KML 规范解释为
WGS84 经度、纬度和可选高度；当前下载范围只使用每个 Polygon 的 `outerBoundaryIs`，
不单独扣除内部孔洞。

KML 模式不会把多边形先扩成外接矩形后整块下载，也不会对每个像素做严格的几何裁切：

- 卫星和 GIS 按与多边形相交的完整瓦片下载，边缘呈瓦片级阶梯形；
- Copernicus DEM 按与多边形相交的完整 1 度分幅下载；
- 标准 XYZ 输出只包含选中的稀疏瓦片；
- 合并大图和 FBX 贴图保留同样的瓦片级范围，支持透明通道的输出在未选瓦片位置保持透明。

任务记录会保存解析后的多边形坐标和原 KML 文件名。任务创建后，即使原 KML 文件被移动，
历史任务配置仍可重新打开。

## 导出配置

导出配置页支持以下输出：

- 卫星 XYZ 切片：适用于 Google XYZ/Web Mercator 等栅格地图源。
- GIS XYZ 切片：按 GIS 分组输出透明 PNG 瓦片。
- 卫星合并大图和 GIS 合并大图：格式可选 PNG 或 JPG，最大边可配置。
- DOM GeoTIFF：可选择卫星和 GIS 数据，按当前导出层级的原始瓦片分辨率输出，
  固定使用 EPSG:3857，不设置人为最大边；超过经典 TIFF 容量时自动写为 BigTIFF。
- DEM GeoTIFF：使用 Copernicus DEM，采样间距按米配置，固定输出 EPSG:3857
  单通道 32 位浮点高程。
- FBX 切片与网格：数据来源可选卫星或 GIS，贴图尺寸可配置。

底板启用“导出高度”后，“采样率（米）”控制 DEM 采样间距，
“每块三角面上限（0不限）”独立控制每个贴图地块的模型预算。旧配置默认 0。
例如 8192 表示每块最多 8192 面，不是整个任务合计 8192 面；复杂块可能用满，
已达到采样误差目标的简单块会提前停止。修改贴图尺寸会改变地块数量，因而影响总面数。
降低预算不会暗中降低 DEM 采样密度，但会增加几何近似误差。
相邻地块共享边统一保留，极低预算下共同简化边界，不能保证任意低预算都不损失地形细节。
任务 JSON、转换记录和 FBX `manifest.json` 保存该上限；CLI 对应
`--fbx-terrain-max-triangles`。

KML 范围导出 GeoTIFF 时，DOM 未选中的瓦片位置使用透明通道，边界仍按与多边形
相交的完整瓦片保留；DEM 范围外像元写为 NoData。中心点 + 半径模式使用完整矩形
导出范围。

卫星输出继续使用当前地图源的缓存目录；GIS 输出使用统一目录：

```text
cache\高德地图\gis数据\
├─ pbf缓存\       # 唯一跨任务复用的原始 PBF
├─ 临时\          # 每个 GIS 组重新生成，不作为缓存
└─ 输出\
   ├─ 瓦片\<组名>\z\x\y.png
   ├─ 大图\<组名>.png|jpg
   └─ FBX\<组名>\...
```

### GIS 分组

配置页会列出全部 GIS 分类。预览页已选分类默认勾选，未选分类可以在配置页单独加入。
左键点击分类组切换是否导出：

- 选中多个单项后，在任意一个单项上右键，将它们合并成一个输出组；
- 右键已合并组，将其拆回单项；拆分后保持原组的选中状态；
- 合并组只输出一个瓦片目录、一个大图文件或一个 FBX 目录。

当前分类和默认颜色为：道路 `#FFDA71`、水 `#6A8ECA`、绿地 `#53854E`、高速
`#FF6F38`、地铁 `#D24BDC`、建筑 `#FFFFFF`、点 `#E53935`、边界 `#363738`、其他
`#607D8B`。预览页颜色修改会传递到导出任务；建筑启用“按高度着色”后，相同高度使用
相同颜色。

## 导出任务页

点击“加入导出队列”后会自动进入任务页。任务按创建顺序串行执行，下载器内部仍按 CPU
核心数自动并发。每条记录显示：

- 排队、导出中、已完成、失败、已取消状态；
- 当前阶段，例如下载瓦片、下载 GIS PBF、渲染 GIS PNG、合并大图或 FBX；
- 百分比和当前完成数/总数；
- 输出目录、创建时间、完成时间和错误信息。

运行中的任务可以点击“取消”。取消会停止继续领取下载/渲染任务；正在进行的底层网络
请求在返回后结束。排队中的任务会直接移除执行队列并标记为已取消。

任务记录保存在 `cache/导出任务.json`。程序重启后仍会显示历史记录；上次退出时处于排队
或运行状态的记录会标记为“失败/已中断”，不会复用临时数据自动恢复执行。任务页的“清除
已结束”只删除已完成、失败或取消的历史记录，不影响运行中的任务。

## 常见使用方式

只导出当前预览范围的 GIS 水体大图：

1. 预览页 GIS 只勾选“水”，颜色设置为需要的蓝色，输入半径。
2. 点击“导出”，在配置页勾选“GIS 合并大图”，取消其他输出。
3. 确认 GIS 输出组只有“水”，选择 PNG/JPG 后加入队列。

同时导出卫星图和 GIS：

1. 在配置页同时勾选“卫星 XYZ/卫星合并大图”和“GIS XYZ/GIS 合并大图”。
2. 选择是否把多个 GIS 分类合并；需要分别输出时保持各分类为单项组。
3. 在任务页观察各组的下载、渲染和后处理进度。
