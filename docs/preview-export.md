# 预览器导出与导出任务

`DomDownToolPreview.exe` 的预览页只负责查看地图和调整范围。点击工具栏的“导出”后，会
进入独立的导出配置页；点击“任务”可以随时查看全部导出记录。旧 WebView2 预览 UI 不再
参与此流程。

## 预览页设置范围

1. 在预览页选择地图来源、GIS 分类和颜色。
2. 使用“中心点 + 半径”时，在“半径”输入导出半径（米）。默认值为 `0`，此时不显示
   范围框。
3. 半径大于 `0` 时，地图中心上方会绘制黄色方框。地图拖动或缩放后，方框会跟随新的
   中心点；实际导出范围是与该范围相交的完整瓦片方形。
4. 点击地图右上角的范围编辑图标，可以连续绘制多个多边形或矩形。黄色表示下载区域，
   红色虚线和斜线表示 GIS 排除区域。区域列表支持选择、定位、改名、启停和删除；
   选中区域后可以拖动顶点、点击边添加顶点，选中顶点后按 Delete 删除。
   工具栏支持撤销、重做和完成；双击、点击起点或 Enter 完成多边形，Esc 取消草稿。
   编辑时可用中键或空格加左键平移地图。
   “底板排除”独立于“GIS 排除”。选中下载区域后，点击名称旁的复制图标
   （提示为“复制为底板排除区”），原样复制当前边界为底板排除区，
   保持原下载区选中；随后调整下载区半径，复制出的边界保持不动。
   选中正方形下载区时，名称下方显示“半径（米）”，表示中心到边的距离。输入后按
   Enter 或点击其他位置，保持区域中心不动调整大小，其他下载区和排除区保持原位；支持撤销、
   重做和任务配置复用。非正方形多边形继续使用顶点编辑。
5. 也可以点击 KML 文件按钮，或把 `.kml` 文件直接拖入预览窗口。导入区域会追加到已有
   下载区，地图缩放到导入范围。半径模式首次切换到绘制时会保留当前方框为一个下载区。
6. 点击“导出”打开配置页。范围模式、层级、地图源、GIS 分类和颜色会从预览页初始化，
   但配置页中的值可以继续修改。

### 自定义范围与 GIS 排除区

导出页的“下载范围”可以在“中心 + 半径”和“自定义范围”之间切换。“编辑范围”会将
当前导出配置带回地图编辑，应用后返回导出页并保留其他组件参数；取消则放弃本次修改。
多个启用的下载区取并集，重叠区域不重复下载，互不相连的区域分别选片。

GIS 排除区只影响建筑、道路、水体等矢量数据及其 PNG、GeoJSON、FBX、Cesium 输出：

- 与排除区相交或接触的建筑整栋剔除，保留建筑的轮廓和高度不会被切开；
- 道路等线要素沿边界裁切，保留区外的各段；普通面要素扣除排除区并保留孔洞；
- 排除区内部及边界上的点不导出；多个排除区共同生效；
- 卫星图、卫星贴图和地形不扣除这些排除区，继续使用完整的下载区域；
- 排除处理在 PBF 解码后进行，原始 PBF 缓存可供不同范围的任务继续复用。

KML 导入支持 KML 2.2
中的 `Polygon`，也支持 `MultiGeometry` 中包含的多个 `Polygon`。坐标按 KML 规范解释为
WGS84 经度、纬度和可选高度；当前下载范围只使用每个 Polygon 的 `outerBoundaryIs`，
不自动把 KML 内环转成排除区，可在编辑器中另行绘制。

自定义范围不会按所有区域的总外接矩形整块下载。栅格和地形维持瓦片或分幅级选择：

- 卫星按与多边形相交的完整瓦片下载，边缘呈瓦片级阶梯形；
- GIS 按相交瓦片获取 PBF，再按实际多边形筛选建筑及裁切其他矢量要素；
- Copernicus DEM 按与多边形相交的完整 1 度分幅下载；
- 标准 XYZ 输出只包含选中的稀疏瓦片；
- 合并大图和 FBX 贴图保留同样的瓦片级范围，支持透明通道的输出在未选瓦片位置保持透明。

任务记录保存每个区域的 ID、名称、类型、启用状态、WGS84 顶点和导入来源，并保存有效
下载多边形。任务创建后，即使原 KML 文件被移动，仍可以通过任务的配置按钮重新打开，
继续编辑下载区和排除区；重新提交会创建新任务，不改写原任务范围。旧 KML 任务会在
读取时自动恢复为可编辑下载区。

## 导出配置

导出配置页支持以下输出：

- 卫星 XYZ 切片：适用于 Google XYZ/Web Mercator 等栅格地图源。
- GIS XYZ 切片：按 GIS 分组输出透明 PNG 瓦片。
- 卫星合并大图和 GIS 合并大图：格式可选 PNG 或 JPG，最大边可配置。
- DOM GeoTIFF：可选择卫星和 GIS 数据，按当前导出层级的原始瓦片分辨率输出，
  固定使用 EPSG:3857，不设置人为最大边；超过经典 TIFF 容量时自动写为 BigTIFF。
- DEM GeoTIFF：使用 Copernicus DEM，采样间距按米配置，固定输出 EPSG:3857
  单通道 32 位浮点高程。
- FBX 切片与网格：数据来源可选卫星或 GIS，贴图尺寸可配置。

地形与跟随地形的建筑均以中心经纬度、海拔 0 为原点，使用 DEM 的 EGM2008 海拔，
保留负海拔。相同中心、相同模型形态的不同范围任务不会因最低高程不同而整体错层；
旧版按范围最低点归零的 FBX 需要重新导出。

外圈低精度底板可沿用原任务的“复制配置”：在“编辑下载范围”中把原 20 公里
下载区复制为底板排除区，再将原下载区扩大到 40 公里；回到配置页降低层级、
增大地块覆盖范围，只保留需要的底板组件。复用时模型中心保留原始坐标精度。
底板排除区在地图上显示为蓝色虚线及斜线，可启停、编辑、删除，支持撤销与重做。
排除只作用于 FBX 底板；不自动排除建筑或 GIS，也不改变 DEM GeoTIFF、XYZ 和合并大图。
只导出底板时，完全位于排除区内的影像瓦片不再下载；边界瓦片仍会下载，
并按边界裁切实际网格。影像和 DEM 原始缓存不会被改写或删除。

底板启用“导出高度”后，“采样率（米）”控制 DEM 采样间距，
“每块三角面上限（0不限）”独立控制每个贴图地块的模型预算。旧配置默认 0。
例如 8192 表示每块最多 8192 面，不是整个任务合计 8192 面；复杂块可能用满，
已达到采样误差目标的简单块会提前停止。修改贴图尺寸会改变地块数量，因而影响总面数。
范围及底板排除边界在简化后精确裁切，边界新增三角面可能使最终面数超过该预算。
降低预算不会暗中降低 DEM 采样密度，但会增加几何近似误差。
相邻地块共享边统一保留，极低预算下共同简化边界，不能保证任意低预算都不损失地形细节。
任务 JSON、转换记录和 FBX `manifest.json` 保存该上限；CLI 对应
`--fbx-terrain-max-triangles`。

### 底板距离档位

底板模型参数页的“贴图距离档位”和“面数距离档位”是两组独立数组，可以增加、删除
档位，分别设置半径（米）和目标贴图尺寸或每块三角面上限。新建底板预填：

| 距离导出中心 | 贴图尺寸 | 每块三角面上限 |
| --- | --- | --- |
| 小于 10000 米 | 基础贴图尺寸 | 基础上限，默认 0（不限） |
| 10000 至小于 30000 米 | 2048 | 10000 |
| 30000 米及以上 | 1024 | 5000 |

距离取导出模型平面坐标中每个块中心与导出中心的水平距离，球面输出使用相同的档位。
各数组独立匹配已达到的最大半径，不依赖输入顺序；同一数组不能有重复半径。
未匹配任何档位时使用基础设置，删除全部档位也恢复基础设置。贴图只缩小，不放大；
其覆盖范围、网格分块布局、UV 和源瓦片下载层级不变。贴图规则不作用于 XYZ、大图
或 GeoTIFF。面数规则沿用地形面数预算功能，仅在底板启用“导出高度”时生效，不改变
DEM 采样精度。

相邻块预算不同时，共享边界按较小的非零预算共同简化并保留相同顶点，内部使用各自
预算。低预算会增加地形近似误差，但不会通过删除三角面留下孔洞。
任务 JSON 的 `distanceLod` 和 FBX 清单的 `distancelod` 保存两组数组；每块元数据记录
`distancemeters`、`outputtexturesize` 和 `terrainmaximumtriangles`。转换记录也保存档位。
旧任务缺少距离规则时使用空数组，保持原有统一精度。

建筑模型的“分块边长 (米)”默认 `2200`，在导出模型的平面坐标中按等长的正方形网格
分块。整栋建筑按平面中心点归入一块，跨格的建筑不会切开，因此模型实际包围盒可能
超过格子边界；墙体与屋顶使用同一个分块编号。球面模型也先按同一平面网格归块。
同一个 `buildings.fbx` 中按分块和材质输出独立节点，各块保持共同原点，材质和贴图
共享，合并贴图模式不会为每块生成重复的 atlas。该参数会写入任务配置和转换记录，
旧记录缺少此字段时使用 `2200` 米。
使用 UE 导入工具时，不要勾选“合并同一 FBX 内的网格”，否则会重新合并这些节点。

KML 范围导出 GeoTIFF 时，DOM 未选中的瓦片位置使用透明通道，边界仍按与多边形
相交的完整瓦片保留；DEM 范围外像元写为 NoData。中心点 + 半径模式使用完整矩形
导出范围。

卫星输出继续使用当前地图源的缓存目录；GIS 输出使用统一目录：

```text
cache\高德地图\gis数据\
├─ pbf缓存\       # 唯一跨任务复用的原始 PBF
├─ 临时\          # 每个 GIS 组重新生成，不作为缓存
└─ 输出\
   ├─ 瓦片\<组名>\z\x\y.png
   ├─ 大图\<组名>.png|jpg
   └─ FBX\<组名>\...
```

### GIS 分组

配置页会列出全部 GIS 分类。预览页已选分类默认勾选，未选分类可以在配置页单独加入。
左键点击分类组切换是否导出：

- 选中多个单项后，在任意一个单项上右键，将它们合并成一个输出组；
- 右键已合并组，将其拆回单项；拆分后保持原组的选中状态；
- 合并组只输出一个瓦片目录、一个大图文件或一个 FBX 目录。

当前分类和默认颜色为：道路 `#FFDA71`、水 `#6A8ECA`、绿地 `#53854E`、高速
`#FF6F38`、地铁 `#D24BDC`、建筑 `#FFFFFF`、点 `#E53935`、边界 `#363738`、其他
`#607D8B`。预览页颜色修改会传递到导出任务；建筑启用“按高度着色”后，相同高度使用
相同颜色。

## 导出任务页

点击“加入导出队列”后会自动进入任务页。任务按创建顺序串行执行，下载器内部仍按 CPU
核心数自动并发。每条记录显示：

- 排队、导出中、已完成、失败、已取消状态；
- 当前阶段，例如下载瓦片、下载 GIS PBF、渲染 GIS PNG、合并大图或 FBX；
- 百分比和当前完成数/总数；
- 输出目录、创建时间、完成时间和错误信息。

运行中的任务可以点击“取消”。取消会停止继续领取下载/渲染任务；正在进行的底层网络
请求在返回后结束。排队中的任务会直接移除执行队列并标记为已取消。

任务记录保存在 `cache/导出任务.json`。程序重启后仍会显示历史记录；上次退出时处于排队
或运行状态的记录会标记为“失败/已中断”，不会复用临时数据自动恢复执行。任务页的“清除
已结束”只删除已完成、失败或取消的历史记录，不影响运行中的任务。

## 常见使用方式

只导出当前预览范围的 GIS 水体大图：

1. 预览页 GIS 只勾选“水”，颜色设置为需要的蓝色，输入半径。
2. 点击“导出”，在配置页勾选“GIS 合并大图”，取消其他输出。
3. 确认 GIS 输出组只有“水”，选择 PNG/JPG 后加入队列。

同时导出卫星图和 GIS：

1. 在配置页同时勾选“卫星 XYZ/卫星合并大图”和“GIS XYZ/GIS 合并大图”。
2. 选择是否把多个 GIS 分类合并；需要分别输出时保持各分类为单项组。
3. 在任务页观察各组的下载、渲染和后处理进度。
