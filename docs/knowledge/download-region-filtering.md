# 多区域下载与 GIS 排除

## 原始区域与有效范围

`DownloadRegion` 保存区域 ID、名称、角色、启用状态、WGS84 顶点和导入来源。
`ExportConfiguration.downloadRegions` 是可编辑的任务快照，不能只保存布尔运算后的轮廓：
差集会丢失被禁用区域和原来的区域边界，之后无法完整恢复编辑。

执行时，启用的下载区生成 `polygonsWgs84`，GIS 排除区单独传入 `GisSpatialRange`。
旧任务的 `kml-polygon` 模式和多边形数组继续可读，并迁移成有 ID 的下载区。
界面复用任务时编辑配置副本，新任务重新入队，原任务记录保持不变。

正方形下载区的半径由保存的四角顶点恢复，含义与原预览方框一致，为中心到边的距离。
调整时围绕原中心缩放顶点，不调整其他区域，也不新增任务字段。输入过程暂存文本，
回车或点击其他位置后一次提交到编辑历史，避免每输入一位数字就产生一步撤销。

## 坐标与裁切

编辑、任务记录及通用选片使用 WGS84；高德解码要素使用 GCJ-02。
`ApplyGisSpatialFilter` 在解码合并后统一把范围转换为 GCJ-02，再进行空间运算。
不要直接用 WGS84 多边形裁切高德要素，也不要改写原始 PBF 缓存。

布尔运算复用 assimp 已依赖的 Clipper 6（polyclipping），经纬度乘 `1e8` 后使用整数坐标。
独立下载区和排除区先统一绕向，以 NonZero 填充规则处理掩膜；重叠下载区取并集，
不能使用 EvenOdd 把重叠部分误当孔洞。要素自身的外环及孔洞使用 EvenOdd 解释。

建筑保留整栋或整栋剔除，排除相交同时检查零面积的边界接触。道路差集输出多个独立
LineString，普通面输出各外环及其孔洞，避免现有 GeoJSON 写出器只写第一段而丢数据。
取消或裁切失败时保留原解码数据，成功后一次性替换。

## 大范围处理与空间索引

解码合并时可通过 `SetFeatureFilter()` 提前选择输出所需的要素。建筑 FBX 和 Cesium
建筑只合并带高度建筑，不让无关道路和复杂区域面进入范围处理。合并采用移动转移，
原始 PBF 缓存仍能供其他导出类型复用。

`GisSpatialIndex` 按每个要素的完整包围盒建立四叉树，查询返回原始输入位置。
跨象限要素留在父节点，避免按中心点归属造成漏选，也不重复插入多个节点。
下载区、排除区及其边界先查询候选；包围盒不经过边界时，才能使用包含关系快速判定。
小建筑还必须通过简单环校验，退化或复杂建筑继续精确判断。

普通面的环按包围盒相交关系分组，保留 Clipper 的 EvenOdd 与严格简单化，
输出使用 `Paths`，避免 `PolyTree` 在拆环期间反复修复全局层级。
结果再通过四叉树和轮廓包含关系恢复外环、孔洞及孔内岛，最后统一绕向。
自接触轮廓拆出的外环可能保留负绕向，不能把所有负绕向环直接认作孔洞。

`SetProcessingProgressCallback()` 上报整理、索引、查询和过滤阶段。
合并、建索引、查询及各个可拆分的几何处理批次都检查取消；单次第三方布尔运算仍不可中断。
取消后不发布部分结果。复杂面病理耗时的定位与实测见 `performance.md`。

## 其他数据路径

卫星及地形不接收 GIS 排除掩膜。FBX 底板使用独立的底板排除掩膜，见下节。
GIS PNG 下载路径在解码后处理
一次；直接调用 PNG Render 的路径单独处理，下载路径渲染前清空范围，避免重复裁切。

## 底板排除与多任务拼接

`DownloadRegionRole::ExcludeTerrain` 保存独立底板排除区域，JSON 为
`exclude-terrain`，旧的 `include` 和 `exclude-gis` 保持原义。
`CopySelectedAs(role, error)` 可复制任意类型区域的原始顶点与来源，
生成启用的副本和新 ID。目标类型由上方当前选中的“下载区域 / GIS 排除 / 底板排除 / 平整区域”
决定，与列表里选中的来源区域类型独立；按钮悬停提示同步显示实际复制目标。
复制后保持原区域选中，因此可以先选择底板排除并复制，再直接扩大原下载区半径；
不以当前地图视图重新计算中心。界面与底层都只检查是否选中区域，不限制源区域类型。
旧实现既限制来源必须为下载区，又将目标写死为底板排除，导致排除区无法复制、
切换目标类型后生成的副本仍不符合选择。回归覆盖四种来源到四种目标的组合、
停用来源、边界精度、撤销重做，以及桌面和窄窗口的类型切换、实际点击与动态提示。
任务复用时用 double 可往返的文本保留中心坐标，避免格式化为六位小数后改变原点。

底板的下载区先求并集，再减去排除区并集。几何运算复用 Clipper 6.4.2；
裁切后包含孔洞的轮廓复用 mapbox earcut 2.2.4 三角化，没有新增依赖。
`FbxTerrainRegionClipper` 使用全局 Web Mercator 米坐标量化，精度为 10 微米。
按轮廓与边界包围盒分别建立四叉树；远离边界的三角面快速保留或剔除，
仅边界候选进入布尔运算，支持多个范围、凹多边形和重叠排除区。
初始化、空间查询和三角面批次均响应取消，单次库运算仍不可中断。

先生成底板网格，再在投影坐标中裁切三角面。原顶点保持不变，
交点按原三角面重心权重插值模型位置、高度和 UV；完成后统一计算法线。
整块落在排除区内的地块不生成贴图和网格，跨边界地块保留外围部分，
不能通过按瓦块中心判断或直接丢弃相交瓦块代替精确裁切。
边界裁切可能增加三角面，面数预算控制的是裁切前地形简化，不应再次简化裁切边而破坏边界。

仅导出 FBX 底板时，选片也跳过完全位于排除区内的目标影像瓦片；
同时输出 XYZ、最高层级瓦片或大图时，仍保留这些产物需要的范围。
GIS/PBF 和 DEM 原始缓存保持可复用，底板排除不会排除建筑；
外围任务若不需要建筑，应关闭建筑组件。

验证覆盖 `FbxTerrainRegionClipperTest` 的面积、孔洞、重叠、绕向和取消，
`PostProcessFbxTest` 的真实 FBX 边界、高度插值及平面/球面导出，
`KmlDownloadRangeTest` 的纯底板选片和其他产物不受影响，
以及 `PreviewRangeEditorTest` 的实际鼠标复制、撤销、重做、保存重开和窄窗口截图。
任务保存恢复由 `DownloadRegionTest` 和 `ExportTaskManagerTest` 验证。

排查时依次检查排除区的类型与启用状态、任务是否沿用原中心、
源范围是否在扩大前复制、导出的三角面是否实际经过裁切，
最后区分整体坐标偏移与不同 DEM 采样、简化造成的局部接缝差异。

## 平整区域与高程采样

`DownloadRegionRole::FlattenTerrain` 的 JSON 类型为 `flatten-terrain`，只通过
`GetRegionPolygons` 获取启用区域，不加入下载区或排除区。新旧两条导出路径均将其传给
`CopernicusDemOptions::SetFlattenPolygonsWgs84`。任务记录沿用完整区域快照，没有新增独立
持久化文件；旧任务没有该角色时，高程采样保持原行为。

`CopernicusDemData::Prepare` 按完整平整区域补齐 DEM 分幅，并在读取原始分幅时累计
有效像元。平均值按 `cos(latitude) / (rows * columns)` 加权，兼容不同纬度分幅列数
变化。统计以原始像元中心是否位于多边形内为准，忽略 NoData，不读取已平整的结果。
OpenCV `fillPoly` 快速生成区域掩膜，`polylines` 标记边界候选；仅边界附近使用现有
点在多边形内的精确判断，避免对所有像元重复遍历复杂轮廓。
逐行检查取消并上报平均海拔计算阶段进度。没有覆盖像元中心的小区域退回原始边界
采样平均；覆盖像元但全部无效时必须报错，不能静默生成海拔 0。

准备成功后区域及平均值不再修改，`Sample` 先按包围盒和多边形判断平整区，返回固定
海拔，否则沿用原双线性采样。重叠区按列表倒序匹配；每个区域的平均值始终取自原始
高程。FBX 地形、DEM GeoTIFF、Cesium 地形和建筑贴地共用该入口，避免底板变平但建筑
仍贴原始山坡。原始 DEM 缓存、海拔零面、下载范围和 GIS 过滤均不改变。
`TerrainFlattenRegion` 保存准备完成的轮廓和平均值，FBX 下载器通过
`SetFbxFlattenRegions` 获取快照。简化后复用 `FbxTerrainRegionClipper` 将网格按平整区
切分为内部和外部，内部顶点重新按同一平均海拔投影，外部三角面连接到同高边界。
这保证小于采样间距的区域也有实际平整面；新增面可能超过简化预算。
Cesium 地形仍沿用其采样和简化精度。

验证包括 `CopernicusDemTest` 的负海拔、凹多边形、重叠、小区域、跨分幅、缓存不变及
取消，`PostProcessFbxTest` 的多块实际网格同高，`GeoTiffExporterTest` 的实际高程像元，
`ExportTaskManagerTest` 的两条执行路径及停用区域，以及 `PreviewRangeEditorTest` 的
桌面和窄窗口绘制、复制、启停、应用、重开与中心精度。

## 多区域选片与验证

通用下载器和 GIS 选片按各区域的包围盒生成候选瓦片，再做相交判断和去重；
不能扫描全部区域的总包围盒，否则高层级、相距较远的两个小区域也会枚举海量空白瓦片。
来源存在偏移时，先筛选目标瓦片，再展开所需源瓦片。

`DownloadRegionTest` 覆盖保存恢复、编辑撤销、坐标转换、建筑剔除、道路分段及面孔洞。
`GisSpatialIndexTest` 对照线性扫描验证查询，`GisSpatialFilterTest` 覆盖复杂面与处理中取消。
`AmapVectorGeoJsonTest` 覆盖建筑预筛选、处理阶段进度、取消以及原始 PBF 复用。
`KmlDownloadRangeTest` 覆盖高层级分离区域和重叠区域去重。
`PreviewRangeEditorTest` 使用生产 HTML 和控制器，在隐藏窗口中模拟绘制、顶点编辑、
导出范围应用和取消，并输出桌面及窄窗口截图到 `tmp/preview-range-editor-test/`。
测试链接专用的离线 WebView 替身，不启动与范围编辑无关的登录窗口和网络服务。
`ExportTaskManagerTest` 验证含启用和停用排除区的任务持久化及重启恢复。
