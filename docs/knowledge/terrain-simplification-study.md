# 低面数地形保形算法对照

日期：2026-09-29。状态：hmm C++ 路线已接入，真实 FBX 数值验证通过，
用户已确认本次测试样本的低面数保形及瓦块接缝效果。

## 目标与范围

目标是在用户指定的面数预算内尽量保留整体地形，而不是靠提高预算或拒绝导出来避免
形变。高光和平滑暂不处理。拓扑错误与几何近似误差分别评价，不能把没有破洞等同于
地形没有失真，也不能把下陷误差直接等同于顶点错误连接。

## 文献与实现

- CGAL Surface Mesh Simplification 提供边折叠及多种代价、顶点放置策略，包括
  Garland-Heckbert 类二次误差方法；还提供边界约束、法线变化与包络过滤策略。
  这些约束不能自动等价为 DEM 每个位置的垂直误差保证。
  官方文档：<https://doc.cgal.org/latest/Surface_mesh_simplification/index.html>
- Cesium Quantized Mesh 是地形网格编码规范，不规定唯一的 DEM 简化算法；
  不应把开源工具的算法当成 Cesium ion 内部实现。
  规范：<https://github.com/CesiumGS/quantized-mesh>
- HERE `tin-terrain` 使用 Terra 贪心插点算法生成 TIN，可输出 quantized-mesh。
  项目：<https://github.com/heremaps/tin-terrain>
- EMODnet QMG Creator 使用 CGAL，为 Cesium 生成 quantized-mesh，提供
  Delaunay、edge-collapse 等不同策略。它是第三方生成器，不是 Cesium 官方内核。
  项目：<https://github.com/coronis-computing/emodnet_qmgc>
- Mapbox Delatin 基于 Garland/Heckbert 的地形高度场近似方法，从误差最大的三角形
  中逐次插点，只更新受影响的局部三角网和误差；公共 `refine()` 可用于自定义面数停止条件。
  C++ 参考实现是 Fogleman `hmm`。
  项目：<https://github.com/mapbox/delatin>、<https://github.com/fogleman/hmm>
- MARTINI 基于 RTIN 层次，适合快速生成多级地形网格，但不是按固定面数最优拟合的保证。
  项目：<https://github.com/mapbox/martini>
- meshoptimizer 提供通用网格简化与边界锁定。本次试验使用默认 `simplify`，
  未为其额外添加高度场单值约束，结果不能代表所有 QEM 或 CGAL 策略。
  项目：<https://github.com/zeux/meshoptimizer>

## 替换前实现的问题

替换前 `src/FbxTerrainTriangulator.cpp` 使用 CDT 完成三角化，但选点与误差控制是项目自己的逻辑：

1. 大高度场按步长减少内部候选点，只额外保留局部极值；误差统计不是覆盖全部 DEM 样点。
2. 每轮按旧网格的误差一次选取最多 256 个候选点，中途不更新误差，可能在同一区域消耗
   多个本可省下的顶点。这里的“可能”是代码层面的风险判断，本实验未单独隔离其贡献。
3. 边界由另一条流程提供，内部选点不会再修正边界误差。因此仅给四个角的实验对它不公平，
   正式对照必须保留原来的边界条件。
4. 旧预算耗尽时直接停止，并不说明整个地形达到误差阈值。

CDT 的二维三角化能力本身和这些选点、预算策略是两回事。实验不能据此认定
“Delaunay 不适合地形”，因为 Delatin 同样采用 Delaunay 三角网。

## 可复现实验

临时目录：`tmp/terrain-algorithm-study/`，未加入项目依赖或正式构建。

- 输入：任务 `1790576658082-0` 的中心地块 `tile_0_0` 与同一份 Copernicus DEM 缓存。
- 中心：WGS84 `(116.134978, 39.951367)`。
- 网格：`1025 × 1025`，共 `1,050,625` 个样点，Web Mercator 间距约 `19.1093 m`。
- 高度：DEM 相对高程加当前球面输出的 local-up 偏移，各候选算法输入相同。
- 测量：独立栅格化每个输出三角形，在全部上述样点计算垂直误差，不采用各库自行报告的
  误差代替统一评价。最大误差指样点上的最大绝对高度误差，不是连续曲面的 Hausdorff 上界。
- 旧算法：从 Git `cbc7f8d` 隔离取出带面数预算的三角化模块，在相同高度场上重新运行。
  这与直接读取旧 FBX 是两项不同实验，不能混为一谈。
- 锁边对照：固定旧模型全部 `1353` 个边界顶点，两种算法每档顶点和三角面数完全相同。
- 固定边界的 Delatin 仅为实验适配：通过私有插点接口植入同一批边界点，边界样点改为
  这些点之间的线性插值，防止继续增加边界顶点；独立评价仍使用未经修改的原高度场。
  该适配不能直接作为正式接口，未来应采用有明确边界约束能力的 C++ 实现。
- 版本：Delatin `0.2.0`、MARTINI `0.2.0`、meshoptimizer `1.3.0`。
  `package-lock.json` 固定了临时实验依赖。

步骤：

1. 在 MSVC 环境运行 `build-probe.ps1`，再执行 `export-probe.exe` 提取离线输入。
2. `baseline-probe.cpp` 与 `baseline/` 内的历史三角化模块单独编译，执行生成旧算法结果。
3. 执行 `node compare.mjs` 生成 `results.json`。
4. 执行 `node verify-repeat.mjs`，确认重复实验的面数、顶点、误差和拓扑指标一致。

## 其他路线

不固定原边界的单块试验：

| 方法 | 三角面数 | 顶点数 | 最大绝对误差 | RMSE |
| --- | ---: | ---: | ---: | ---: |
| Delatin | 4095 | 2094 | 36.12 | 10.67 |
| Delatin | 8191 | 4165 | 23.26 | 6.59 |
| Delatin | 16384 | 8292 | 20.14 | 4.22 |
| MARTINI | 4087 | 2108 | 68.21 | 12.64 |
| MARTINI | 8183 | 4188 | 52.56 | 8.70 |
| MARTINI | 16384 | 8327 | 30.76 | 5.85 |

meshoptimizer 从完整规则网格出发，使用宽松误差上限尝试达到相同预算。
该默认配置出现水平投影反向三角形、投影退化和重叠覆盖，不符合本工具的单值高度场
要求；这里不以其较低的平均误差宣称胜出。投影退化不等于三维三角形面积为零，
投影反向也不能直接推广为该库的通用三维网格存在错误。

MARTINI 的选择阈值、meshoptimizer 的二次误差以及 Delatin 的最大样点误差含义不同，
不能直接比较它们返回的 `error` 数字。Delatin 细化时的 Delaunay 换边也可能造成某一
预算点的瞬时最大误差上升，因此不能把每加一个点都保证全局最大误差下降当作接口承诺。

本次未编译运行 CGAL 或 EMODnet，相关结论仅来自文档与接口研究。不同方法的边界条件、
预计算以及实验适配开销不同，耗时不作为本轮选型的胜负依据。

## 推荐与未验证项

建议优先验证 Terra/Delatin/hmm 类的地形专用渐进近似，保留成熟三角化内核，替换本项目
批量候选选点策略。下一步应先选择可维护且许可证适配的 C++ 实现，再接入正式导出。
CGAL 的约束边折叠保留为对照路线，不应仅因库名而认定它在这份数据上更好。

正式接入需要：

- 用户面数预算与高程采样间距分离；预算是形状近似的资源限制，不暗中降低 DEM 采样密度。
- 地块共享边统一规划并固定，不能用独立减面或裙边遮挡代替接缝一致性。
- 跨块分配预算时按地形误差分配，而不是让所有贴图块机械使用相同额度。
- 保持高度场拓扑，导出前验证覆盖、翻折、退化、相邻块边界及数值有效性。
- 同时统计实际三角面数、索引顶点数、误差分布与最坏位置。
- 用完整任务、多种山地/KML/细长边界，以及最终 FBX 重导入和 UE 视图验证。

本轮只证明这一中心地块的同预算保形明显改善，未证明所有地形或任意低面数都能保持
极小误差，也未完成跨块接缝、最终 FBX 和 UE 视觉验收。不得据此宣布塌陷问题已修复。

## C++ 接入与复测

以下是选型实验之后的实现验证，不能与上述 JavaScript 原型结果混用。
采用 hmm 的半边局部细化、整数换边谓词和索引堆，CDT 仅初始化固定边界。
版本、许可与适配说明见 `../../third_party/hmm/README.md`。
没有引入 CGAL、GLM 或新的运行时依赖。

`native-probe.cpp` 调用正式 C++ 三角化模块，输入仍为之前的
`heights.f64`（包含球面 local-up）和旧模型 1353 个边界点。

### 预算语义与限制

- 第一版为每贴图地块的上限，不是全任务全局误差分配预算。达到误差目标的块提前停止，
  不强行凑面。跨块按误差全局分配预算尚未实现。
- 0 不限；正预算严格满足上限，极低预算（测试至 2 面）仍输出完整矩形。
  若边界点过多，先按边界高度误差共同简化共享边，留出内部预算，不独立裁掉三角面。
- 无拓扑破洞不等于无形变。8192 档中心块仍有约 25 米下陷，预算越小，细节损失越大。
  不承诺任意低面数下“任何塌陷都没有”，也没有修改用户已决定暂缓的高光/法线逻辑。
- 自动回归覆盖预算、完整样点误差、随机/细长网格及 FBX 多块接缝，UI 参数布局、
  配置序列化恢复和 CLI 构建。Release 全量 37 项中 35 项通过；
  既有百度坐标样例、Google 本地代理断言仍失败。
- 2026-09-29 用户实测确认：更低面数下保留了更好的整体形状，瓦块接缝稳定，
  同意提交当前版本。该验收针对本次测试样本，不代表任意地形或任意预算下的误差保证；
  高光问题仍按此前约定暂不处理。
- 尚未用完整复杂 KML/全球极区数据做新算法的数值审计。

### 距离档位与共享边界

2026-10-09 增加每块按距离选择的面数预算。贴图尺寸和面数使用独立规则数组；
按模型平面坐标中的块中心水平距离匹配，不改变 DEM 采样网格或贴图覆盖范围。

原来的接缝同步过程使用统一预算。改成逐块预算后，如果共享边由两侧分别限点，
近处高预算块可能保留远处低预算块没有的边界顶点，形成 T 型接缝。
因此共享边先合并候选点，再以两侧较小的非零预算共同简化一次，复制给两侧。
0 表示不限，不参与较小值比较；两侧都不限时不削减边界。外边界使用本块预算，
块内部仍使用各自预算，不能为了保持接缝而强行把整块降成邻块的预算。

回归使用离线生成的起伏高度场和 49 个贴图块，覆盖 0、128、31 三档预算，
并重读平面和球面 FBX 检查实际逐块面数。平面网格额外检查块内开放边及相邻块
边界的位置、高度、法线一致性。贴图同时验证 512、256、128 三档实际像素尺寸。
这些合成数据不代替复杂真实地形的误差审计或 UE 视觉验收。

以后排查跨档位裂缝，先检查共享边两侧的采样网格是否一致、是否只限点一次、
0 是否被误当成最小预算，以及实际面数和元数据中的有效预算是否对应。
