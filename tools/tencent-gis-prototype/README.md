# 腾讯矢量 GIS 前端协议验证

当前阶段用于回答：腾讯矢量的信封、差分坐标、分类和建筑高度能否在前端独立还原，
与腾讯栅格底图对齐，并在多个区域、数据层级上保持一致。验证完成并经查看后，
再按确认的规则接入 C++。本工具不改变正式应用的 GIS 来源或现有任务格式。

## 运行

需要现有 Node.js 运行环境，项目根目录执行：

```powershell
node tools/tencent-gis-prototype/server.mjs --port 8776
```

打开 `http://127.0.0.1:8776/`。选择样区或输入 GCJ-02 坐标，加载一个或九个完整瓦片。
支持电子/卫星底图、分类开关、建筑高度着色、要素属性、瓦片边界和筛选 GeoJSON 导出。
“协议核对”的对比按钮会重新请求同一批 `compress=0` 瓦片，与前端还原的
`compress=1` 结果按几何、图层和原始属性逐一比较。

GCJ-02 坐标直接与同坐标系底图比较，不伪称为 WGS84；
验证 GeoJSON 顶层和要素属性均标注坐标系，后续正式导出需要显式坐标转换。
图层数量包含完整瓦片及其边缘缓冲区，不代表行政区域内或半径裁剪后的唯一实体数量。
跨瓦片保留原始要素，不在本阶段猜测去重或面拓扑合并规则。

检查建筑轮廓精度时，请选“数据层级 18”并重新加载。地图滚轮缩放只改变显示层级，
不会重新下载更精细的数据；默认 z16 放大后会暴露源数据的简化与整数坐标量化。
同区对照已确认 z18 的尖角、三角形和接触明显减少。压缩对照一致不等于轮廓精度合格。

## 协议边界

- 依据当前官方 GL SDK 的 `vectorSrc`、`styleNameConfig`、`H/X` 差分还原、
  `lt` 信封处理及 `getOriginalGroundFeatures` 高度逻辑。
- 请求使用 GCJ-02 Web Mercator XYZ 选块，在 HTTP 边界转换为 TMS Y。
- SDK 配置给出最大矢量数据层级 18；页面区分固定数据层级和当前地图显示层级。
- SDK 中明确的业务标签用于分类；保留原始腾讯 layer ID、样式名、原始字段及未知样式。
  点和文字不会因为名称含有 building 或 road 就被误判为建筑面、道路中心线。
- 只有已核对的 `196619` 数值字段标为建筑米制高度；其他建筑分类不推测字段含义。
- 压缩几何按每条路径分别差分累计。坐标可以超出 0–256，保留边缘缓冲。
  成组文字拆分并保留来源，几何环闭合，错误响应和未知几何类型明确报错。
- 真实响应可能含两个顶点或零面积的退化面。此类要素保留原始坐标和属性，
  GeoJSON 使用 `geometry: null` 并记录 `geometryIssue`；不绘制伪造面。
  图层总数、可绘制数和退化数因此可能不同。
- 样式筛选按当前地图显示层级检查官方样式区间，缩放后重新计算；
  原始要素属性中的 `styleVisible` 则记录下载数据层级时的检查结果。
- 地点与文字显示为锚点；本阶段不复刻 SDK 的字体图集、文字避让和道路文字排版。
- 本阶段将嵌套面路径保留为多个独立面；若出现带洞编码，需要补充真实样本
  并核对 SDK，再确定正式拓扑规则。没有把未验证的路径当作洞。
- 不加载 SDK 的动态执行逻辑；仅从官方脚本提取数字数组分类表，使用 JSON 解析。
  JSON/Base64/UTF-8 复用浏览器标准 API，只实现腾讯特定字节变换与差分坐标。
- 地图交互使用 Leaflet 1.9.4，图标使用 Lucide 0.468.0；不新增 C++ 库。
  官方 SDK、样式、前端依赖和原始地图响应只缓存到 `tmp/tencent-gis-prototype/`。
  本地服务仅监听 `127.0.0.1`，上游地址固定，不支持任意 URL 转发。

## 后续

这是一份可删除的验证原型。经验证的规则和限制记录到 `docs/knowledge/`；
后续由腾讯专用 C++ 模块复用现有渲染、空间过滤与导出后端，不能复用高德 PBF 解码器。
该 SDK 内部接口可能变化，正式版本应集中管理版本和格式错误处理。

## 本轮验证

2026-10-23，数据版本 405、样式版本 99：

- 北京、济南、上海、广州分别在 z12、z14、z16、z18 对照，共 16 组、
  6,820 个要素，压缩还原与未压缩数据的图层、坐标和原始字段全部一致。
- 北京 z16 连续九瓦片共 6,253 个要素，对照全部一致；其中 15 个为退化面，
  可绘制 6,238 个要素。保留的建筑记录 4,685 个，可绘制建筑 4,670 个。
- 16 组样本的正建筑高度范围合计为 4–240 m；z12/z14 样本没有带高度建筑。
  当前样本未知样式为 0，尚未遇到补充 `pois`、嵌套多路径或带洞编码。
- Playwright 在 1440×900 和 390×844 检查地图像素、电子/卫星底图、
  分类开关、属性点击、压缩对照、筛选导出、层级筛选、非法坐标和取消加载，
  无页面脚本错误及横向溢出。

本机验证脚本、原始瓦片、报告和截图均位于忽略目录 `tmp/tencent-gis-prototype/`。
正式实现前仍需确定带洞拓扑、跨瓦片去重/裁剪和 GCJ-02 到 WGS84 的输出规则。
